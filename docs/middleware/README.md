# Middleware Docs

This folder contains middleware/BFF-focused documentation: API contracts, data model standards, and developer workflow guidelines.

Files:
- data_model_and_api_contracts.md — Canonical data entities, API standards, error contracts, event naming, API governance
- admin_bff_api_contracts.md — Frontend-facing Admin Console BFF contracts for auth, audit, and config lifecycle
- pull_request_guidelines.md — PR quality standards, commit rules, review practices, merge readiness

Refer to docs/backend for platform-level architecture and docs/frontend for UX guidance.
