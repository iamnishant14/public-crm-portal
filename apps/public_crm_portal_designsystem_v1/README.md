Public CRM Portal — Design System (v1)

This package contains design tokens and shared UI components for the Public CRM Portal.

Folder name follows: public_crm_portal_designsystem_v1

Quick start (after installing deps):
1. cd apps/public_crm_portal_designsystem_v1
2. npm install
3. npm run storybook

Files:
- src/: components
- tokens.json: design tokens
- .storybook/: Storybook config
