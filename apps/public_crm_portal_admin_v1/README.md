Public CRM Portal — Admin (v1)

This folder contains the Admin Console frontend (Next.js) for the public-crm-portal project.

Naming convention: folder uses the standard public_crm_portal_{model_name} so multiple versions can coexist.

Quick start:
1. cd apps/public_crm_portal_admin_v1
2. npm install
3. npm run dev

Follow docs/frontend/UI_DEVELOPMENT_PLAN.md for milestones and next tasks.
